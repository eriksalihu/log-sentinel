# Security policy

## Reporting a vulnerability

Please do not report security problems in a public issue.

Report them privately through GitHub's private vulnerability reporting, which is enabled for this repository:

1. Open the [Security tab](https://github.com/eriksalihu/log-sentinel/security) of this repository.
2. Choose **Report a vulnerability**, or go straight to the [new advisory form](https://github.com/eriksalihu/log-sentinel/security/advisories/new).
3. Describe what you found, how to reproduce it, and which commit you tested.

The report is visible only to you and the maintainer unless a security advisory is published.

## Scope

This is a small defensive security project. All sample data in it is synthetic, so the repository contains no real credentials, addresses or personal data. If you find anything that looks real, please report it the same way.
